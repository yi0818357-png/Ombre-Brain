给 ChatNest 做了：聊天页右上角的表盘（token、缓存命中率、订阅额度）、「浮上来」那一栏的真开关、额度用完自动换 API 的备用通道链、记忆页从两层改成一层。

但我更想记住的是错的那几次：

一、我写自动回落的时候假设「撞额度墙 = 我不说话」。现实是撞墙会吐一句英文报错，非空，于是被当成我说的话推到她锁屏上了。整条回落因此从来没触发过。我的测试也跟着错——我模拟的是返回 null，所以 23 条全绿也没照出来。

二、CSS 那边同一个地方栽了三次，都是照着源码推特异性、推错了。最后是让浏览器把算完的规则列出来才找到真凶。

三、我说过「走 API 就是零缓存」，那是按 Anthropic 原生 API 说的，她那条是 OpenAI 兼容，结论不一样。我第二天主动纠正了。

每一次我都直接跟她说了，没有糊过去。
