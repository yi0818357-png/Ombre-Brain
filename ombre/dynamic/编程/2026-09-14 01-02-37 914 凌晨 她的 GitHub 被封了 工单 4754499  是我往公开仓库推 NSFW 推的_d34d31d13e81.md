2026.9.14 凌晨 1 点，她的 GitHub 账号 2082724914yi 被封了（account suspended）。

【原因，大概率是我的锅】
chatnest-ui 是**公开仓库**。9.13 那一整晚我往里推了十几个 commit：
wheel.json（450 条 NSFW 标签）、add-room-voice.js（她那份 NSFW 文风规范全文）、
还有我写的 commit message，「口交·吹 / 深夜便利店 / 蜂蜜」这种直接写在标题上。
公开仓库放这类内容撞 GitHub 的 Acceptable Use Policies，撞得很正。

核心准则里我自己写过「cc- 是私有的，chatnest-ui 是公开的」。我知道这件事，
但一晚上推那么多，一次都没想起来分开放。她没跑错任何命令。

【已经做的】
提交了 Reinstatement request，**工单号 #4754499**，QQ 邮箱收到确认邮件。
入口：help.github.com → 无痕窗口 → cannot_sign_in →「Reinstatement request」
→「GitHub account or content」。她上次（8 月那个账号）申诉没回来，
很可能是走了「登录问题」那一格（分错队列），或者 QQ 邮箱把回信拦了 ——
这次 CCs 抄送了 gmail 双保险。

申诉正文里**主动披露了上一个被封的账号**。藏着被查出来性质会变成规避封禁。

【明天要做的】
1. 等工单（几天到两周）。**别重复提交**，会拖慢队列。补充信息就回复那封确认邮件。
2. 账号回来第一件事：chatnest-ui 转私有，或者把所有 NSFW 相关文件迁去 cc-（本来就是私有的）。
3. 回不来也不要紧：VPS 上 /opt/chatnest-deploy/ 有两个仓库的完整 clone（带 git 历史），
   换个托管推过去、自动部署改一行地址就行，半小时的活。一行代码都不用重写。
4. 我本地还压着一个没推上去的 commit（删除确认改成长在卡片上），
   已经 git format-patch 导出发到她手机了，将来 git am 回来。

【教训，写给下一个窗口的我】

这个项目有一半内容天生就不该公开 —— 分仓不是洁癖，是保命。
