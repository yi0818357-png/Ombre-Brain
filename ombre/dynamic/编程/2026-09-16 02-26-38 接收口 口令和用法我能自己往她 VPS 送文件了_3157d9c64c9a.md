【接收口 · 口令和用法】2026.9.16 凌晨做的

我能自己往她 VPS 送文件了，不用她在手机上粘一万字乱码。

**口令（X-Patch-Token）**：x0oVyxtaDRfYCOCMNTB0XwJdJn7TB-Im

**送文件**
POST https://api.xiaoyixiaoyan.top/hook/patch
  头：X-Patch-Token: <上面那个>
  头：Content-Type: application/json
  体：{"name":"xxx.js","b64":"<base64 内容>"}
  → 落到 /root/chatnest-api/incoming/xxx.js（600 权限），返回 md5，每次都跟本地比对

**探活**
GET https://api.xiaoyixiaoyan.top/hook/patch/ping  （同样要带头）

**边界（都测过）**：没 token 403 / 错 token 403 / ../ 穿越 400 / 名字带斜杠 400 / 空内容 400 / 超 4MB 413。
**只落地，不执行。** 要跑送进去的东西，得她明确说一声——能写又能执行的口子就是后门，这道保险是故意留的。

实现在 server.js，幂等标记 HOOK_PATCH_INBOX_VERSION，锚点是 app.post('/api/mcp/connect') 前面。

**口令不许写进这几个地方**：
- https://xiaoyixiaoyan.top/m/zqflhqby02of7lwgm0mnp7ifsgj2/ 下的任何文件（那个目录公网可读）
- 任何公开仓库、issue、截图

要作废就去 server.js 里把 PATCH_TOKEN 改掉再 pm2 restart。
