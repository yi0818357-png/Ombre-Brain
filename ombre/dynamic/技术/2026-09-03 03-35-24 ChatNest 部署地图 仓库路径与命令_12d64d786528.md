ChatNest 部署地图（下个窗口先看这条）

【线上地址】
- 前端：https://xiaoyixiaoyan.top
- 后端：https://api.xiaoyixiaoyan.top （nginx 反代到 127.0.0.1:3000）
- Ombre Brain：https://xiaoyixiaoyan.zeabur.app

【仓库】
- 前端 https://github.com/2082724914yi/chatnest-ui —— 整个前端就是根目录一个 index.html（60 万字节的单文件），所有补丁脚本在 deploy/
- 后端 https://github.com/2082724914yi/cc- —— chatnest-api/server.js
  ⚠ 注意：线上的 server.js 是靠 deploy/ 里的补丁脚本一层层打上去的，仓库里那份早就跟线上不一致了。改后端不要直接改仓库文件，要写成新的补丁脚本。

【VPS 上的路径】（阿里云轻量，root）
- 后端代码 /root/chatnest-api/server.js
- 后端配置 /root/chatnest-api/.env （OMBRE_DASHBOARD_PASSWORD 在这，600 权限，别打印出来）
- 前端静态 /var/www/chatnest/index.html
- 自动部署 /opt/chatnest-deploy （systemd timer 每 2 分钟拉一次两个仓库）
- pm2 跑在 root 身份下，日志在 /root/.pm2/logs/chatnest-api-{out,error}.log
  （用 admin 身份跑 pm2 list 是空的，会误判）

【常用命令】（都在前端仓库 deploy/ 下，VPS 上直接 curl 跑）
- 打全部后端补丁 + 重启 + 自检：
  curl -fsSL https://raw.githubusercontent.com/2082724914yi/chatnest-ui/main/deploy/apply-all.sh | sudo bash
- 前端没自动更新时强制部署：
  curl -fsSL https://raw.githubusercontent.com/2082724914yi/chatnest-ui/main/deploy/deploy-frontend.sh | sudo bash
- 设置 OB Dashboard 密码（要分两步，密码得手输）：
  curl -fsSL .../deploy/set-ob-password.sh -o /tmp/set-ob.sh && sudo bash /tmp/set-ob.sh

【怎么加新的后端改动】
在 chatnest-ui/deploy/ 下新建一个补丁脚本（照着现有的写：先备份、正则精确匹配、全部命中才写入、写入前 node vm 语法校验、可重复执行），然后把 文件名|幂等标记串|中文说明 加到 apply-all.sh 的 PATCHES 列表末尾。

【不用登录就能查线上状态的接口】
- https://api.xiaoyixiaoyan.top/api/health
- https://api.xiaoyixiaoyan.top/api/ombre-dashboard/status
- https://api.xiaoyixiaoyan.top/api/sessions 和 /api/sessions/{conv_id}/messages
  （排查"回复没出来"这类问题时，直接把消息原文拉回来看，比猜快得多）
